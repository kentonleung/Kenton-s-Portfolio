# Portfolio Website

A simple static portfolio website vibe coded and pushed on GitHub in VSCode. It uses MCPs to extract data from my project reports in PDFs and an existing portfolio in PPTX format.

## Files

- `index.html` — main portfolio page
- `styles.css` — styling for layout and theme
- `script.js` — scroll reveal enhancement
- `projects/` — dedicated project detail pages
- `ppt_images/` — extracted PowerPoint visuals used on the site
