# Portfolio Website

A simple static portfolio website scaffold built with HTML, CSS, and JavaScript.

## Files

- `index.html` — main portfolio page
- `styles.css` — styling for layout and theme
- `script.js` — scroll reveal enhancement
- `projects/` — dedicated project detail pages
- `ppt_images/` — extracted PowerPoint visuals used on the site

## Customize

1. Replace `Your Name` with your name.
2. Update the text in the About, Projects, and Skills sections.
3. Change the email address in the contact button.

## Preview
Open `index.html` in your browser to view the portfolio site.
