Project

Unlimit Hosting Revamp

Revitalized a 20-year-old hosting provider website with improved user flow, AI tooling, and stronger security.

Back to Portfolio View live site

Overview

This project updated a legacy web hosting provider by modernizing the website experience, cleaning up service tiers, and adding intelligent domain search tools.

Problem

The existing site relied on retired plugins, outdated designs, manual WHOIS tools, and cluttered pricing plans.

Solution

  • Redesigned landing pages, service plans, and tiered bundles for clarity.
  • Built a domain availability search using the DomScan REST API.
  • Integrated an AI chatbot and domain name generator using Groq meta llama.
  • Upgraded security with Cloudflare, HSTS, and modern TLS settings.

Role

Full stack web development, UX redesign, API integration, and security upgrades.

Highlights

  • AI chatbot + domain generator
  • DomScan REST API domain lookup
  • Cleaned service plan logic
  • PHP 8 and Cloudflare security
