Project

Unlimit Hosting Revamp

Revitalized a 20-year-old hosting provider website with improved user flow, AI tooling, and stronger security.

View live site

Project Snapshot

  • Role: Full-Stack Web Developer
  • Tech Stack: RESTful APIs, Cloudflare, JavaScript, PHP, OpenCart, SEO
  • Key Outcome: Engineered the end-to-end architecture of a 20-year-old legacy hosting platform, achieving perfect Google Lighthouse scores, integrating AI-driven tools, and deploying enterprise-grade security.

The Challenge

The website was a 20-year-old legacy system relying on deprecated plugins, outdated design patterns, manual WHOIS lookups, and confusing pricing tiers. The business needed a modern, competitive web presence to retain and attract hosting customers.

UX Redesign & Service Plans

Restructured landing pages and service bundles for clarity. Simplified pricing logic to guide customers toward appropriate plans. Redesigned responsive layouts for mobile-first discovery, reducing friction in the sales funnel.

Domain Search & AI Tools

  • Domain availability search: Integrated DomScan RESTful API for real-time domain lookups, replacing the old manual WHOIS UI scraping script.
  • AI-powered tools: Built a domain name generator and customer service chatbot using Groq RESTful API (Meta Llama 3.1 70b versatile) for instant support and domain ideation.

Security & Infrastructure

  • Updated PHP 8 and optimized landing page video preloading techniques for performance improvements.
  • Deployed Cloudflare DNS, WAF, and Turnstile captcha, anti-bot scripts, honey pot tricks, API rate limiting for enterprise-grade security.
  • Updated HSTS and modern TLS protocols for end-to-end encryption, upgrading from a B to an A+ certification on Qualys SSL Labs.
  • Achieved all green Google Lighthouse scores, and set up Seobility for search engine optimization.

Impact & Results

Delivered a modernized hosting platform with full-stack improvements: cleaner UI/UX, intelligent domain discovery, AI assistant, and enterprise security, performance increase, security increase, search engine optimized. The site now competes with modern local hosting providers while maintaining custimizability and customer data integrity from the client's preferred OpenCart CMS..
