Project

Heart Finite Element Model

Simulated blood velocity and pressure in the heart using finite element analysis and mesh fidelity studies.

Back to Portfolio

Overview

This academic model evaluates heart pressure and velocity using discretized finite element methods and convergence analysis.

Approach

  • Computed a discretized weak form for blood flow in the heart.
  • Analyzed mesh fidelity and pressure drop across simulated domains.
  • Conducted convergence testing to validate accuracy.

Outcome

Demonstrated improved accuracy with finer meshes and identified the point of diminishing returns beyond the fifth refinement.

Role

Finite element modeling, simulation analysis, and convergence validation.

Key findings

  • Mesh fidelity impacts pressure drop accuracy
  • 2D velocity and pressure modeling
  • Convergence tests showed diminishing returns
