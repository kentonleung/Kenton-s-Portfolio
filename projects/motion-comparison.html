Project

Motion Comparison System

Developed a system to analyze synchronicity of actions, movements, and gestures (AMG) between individuals, linking to teaching quality.

Project Snapshot

  • Tech Stack: Unity, MATLAB, Nuitrack SDK, C#, Intel RealSense D435
  • Key Outcome: Engineered a markerless 3D motion-tracking pipeline to quantify human synchronicity.

The Phenomenon: Quantifying Classroom Synergy

When expert lecturers co-teach, a fascinating physical phenomenon occurs: their Actions, Movements, and Gestures (AMG) naturally synchronize. While widely observed, this theory lacked quantitative backing. This project set out to translate that abstract observation into hard data by engineering a custom, dual-instructor motion-capture and analysis pipeline.

The Capture Engine: Hardware & Biomechanical Tracking

To avoid the physical constraints and expense of traditional marker-based motion capture, I built a markerless tracking system using an Intel RealSense D435 camera. Integrated with the Nuitrack SDK and developed in Unity, the capture engine extracts real-time 3D spatial coordinates across up to 20 biomechanical joints.

Crucially, I engineered a custom normalization script to scale the skeletal data. This ensured the system evaluated the content of the motion independently of the subjects' varying physical heights and proportions.

The Algorithm: Aligning Time and Motion

Human movement naturally varies in speed and duration, making simple frame-by-frame comparisons impossible. To solve this, I developed a post-processing analysis system in MATLAB.

The system utilizes Dynamic Time Warping (DTW) to non-linearly align the temporal sequences of two different instructors. Once time-aligned, the algorithm applies a Motion Similarity Measure—derived from Pearson’s correlation coefficient—to generate an objective synchronicity score between -1 and +1.

Validation & Edge Cases

To validate the architecture, the system processed 30 data samples from five subjects performing specific lecturing gestures (pointing, nodding, referencing).

  • The Result: Successfully differentiated gestures, yielding an average intra-task similarity score 3.97% higher than the inter-task score.
  • The Edge Case: The system proved highly accurate for sweeping movements but struggled to score subtle actions—like head nodding—due to the incredibly small range of motion and the risk of filtering micro-movements as "idle" frames.

The Next Evolution

This proof-of-concept established the first quantitative framework for measuring instructor synchronicity. The next technical evolution of this project involves merging the Unity capture environment and MATLAB analysis into a single, unified software application to improve the user experience. To drive this forward, the project has been handed over to a student in the next cohort, who is continuing the work by applying Machine Learning-based comparison methods. This integration will allow the system to automatically classify distinct gestures and intelligently filter idle frames, paving the way for further research into how physical synchronicity impacts student learning outcomes.
