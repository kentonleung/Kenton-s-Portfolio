Project

Low-Cost Smart Insole

Created a lightweight, low-cost wearable insole prototype for activity monitoring and gait analysis.

Back to Portfolio View repo

Overview

Designed a smart insole prototype that monitors gait and classifies physical activity using sensor data and embedded firmware.

Highlights

  • 3D printed TPU prototype and manual insole cut-outs for comfort.
  • Gait event detection compared against force plates.
  • Activity classification accuracy and trend analysis.

Role

Hardware prototyping, sensor integration, and embedded system development.

Notes

  • Comfort-focused prototype design
  • Low-cost sensing approach
  • Comparative lab testing
