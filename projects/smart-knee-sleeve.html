Project

Smart Knee Sleeve

Built a wearable knee sleeve with IMU sensing, wireless data logging, and biomechanical analysis dashboards.

Back to Portfolio View repo

Overview

Developed a knee sleeve system using ESP32 and BNO055 IMUs to capture knee angle, stride, and gait metrics with wireless visualization.

Features

  • IMU-based motion tracking and wireless logging.
  • Grafana dashboards for live visualization.
  • Biomechanical accuracy evaluation against gait lab data.

Role

Electronics, firmware, and testing lead for wearable biomechanics.

Key results

  • Wireless knee angle and stride metrics
  • Grafana visualization of motion data
  • Device accuracy compared to lab ground truth
